# Roll Interieurintake (intake.roll.nl)

Intakeflow voor de interieurstyliste. Vite + React + TypeScript + Tailwind, zelfde
stack als de kleuradviestool en de Visualizer.

## Lokaal draaien
```bash
npm install
cp .env.example .env   # vul de Supabase-waarden in
npm run dev            # http://localhost:8081
```
